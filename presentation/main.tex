\begin{frame}{Think while listening}
  \begin{itemize}
  \item A cascaded voice agent on an edge device answers seconds after the
    user stops: a median \TTFAMulti\,ms here, on spoken multi-step problems.
  \item The field's answer: start the language model on partial transcripts,
    so part of the reply is ready at the endpoint.
  \item Its assumption: compute is idle while the user speaks.
  \item On a unified-memory system-on-chip it is not. Recognizer, reasoner
    and synthesizer share one memory system and one set of cores.
  \end{itemize}
  \bigskip
  \alert{Which speculation should the listening window be spent on?}
  \note{
    \begin{itemize}
    \item TTFA: time to first audio, from the true end of speech (known to
      the file source) to the first reply audio.
    \item \TTFAMulti\,ms is the median TTFA of the reactive pipeline without
      partial decodes (REACTIVE-NOPARTIAL) on the 80 seeded multi-step items,
      three runs. Its n in turns is printed on Fig.~1; its scorer prints no
      interval for it.
    \item The field's designs: input-time speculation, semantic triggering,
      endpoint anticipation, simultaneous inference; spoken language models
      pursue the same idea inside one model. They assume idle compute.
    \item Here a speculative decode is paid for by whatever runs next to it.
      The talk prices both kinds of speculation on one axis.
    \end{itemize}
  }
\end{frame}

\begin{frame}{Testbed}
  \begin{itemize}
  \item \textbf{Device.} Jetson Orin Nano Super, 8\,GB unified memory,
    MAXN\_SUPER with clocks pinned; desktop state recorded per run.
  \item \textbf{Pipeline.} Silero VAD; Whisper \texttt{tiny} (hypotheses) and
    \texttt{base} (final), int8, on three shared CPU cores; a 4-bit
    Gemma~4~E2B in llama.cpp, all layers on the GPU, one slot; Piper.
  \item \textbf{Sets.} Dev (16 short spoken queries); Spoken-MQA short and
    long digit splits (20 each); multi-step (80 seeded items, and their 20
    longest).
  \item \textbf{Protocol.} Audio played in at real time through the capture
    path; arms paired per item, each item's median over three runs,
    bootstrap 95\% CI over items.
  \end{itemize}
  \note{
    \begin{itemize}
    \item The language model runs on the other three cores; recognizer and
      reasoner share one memory system.
    \item The next file starts only after the reply has finished and a quiet
      period has passed, so turns never overlap.
    \item Excluded: turns split by the VAD, turns whose endpoint fired after
      the final, runs that fail a registered validity check.
    \item Analyses that depart from paired-per-item say so on their slide
      (the tax: one run per condition; the overlap fit: intervals over
      runs).
    \item Pre-registration: predictions, bars and scoring rules committed to
      the lab notebook before the runs that test them; corrections appended,
      never edited in.
    \item Spoken-MQA's single-step split selected the listener's
      configuration and tested preemption.
    \end{itemize}
  }
\end{frame}

\begin{frame}{One window, two consumers}
  \[
    \mathrm{TTFA} = s + F(D - C) + L + S + O
  \]
  \begin{itemize}
  \item \textbf{Listener.} Decodes the uncommitted audio with a small model
    and commits the words consecutive hypotheses agree on: it shrinks
    $D - C$.
  \item \textbf{Thinker.} Drafts the reply at fraction $f$ of the utterance;
    usable with probability $p_{\mathrm{usable}}(f)$, worth issuing only
    above a break-even $p^\ast$.
  \item A draft must finish inside the window $w(f) = D(1-f) - d(fD)$.
  \item Neither $D$ nor the endpoint is known while the user speaks.
  \end{itemize}
  \note{
    \begin{itemize}
    \item $s$: the VAD's settle time. $D$: the audio held at the endpoint.
      $C$: the audio committed before it. $F$: the final decode of the
      uncommitted tail, close to affine in its audio. $L$: the language
      model's first token. $S$: the synthesizer's first chunk. $O$: audio
      output.
    \item A hypothesis still decoding at the endpoint competes with the
      final for the same cores, unless it is stopped.
    \item $d(fD)$: the decode of what has been heard. A draft that cannot
      finish before the endpoint is all cost.
    \item A rule must judge, per consumer, whether work issued now is
      feasible; for the thinker, also whether it is valuable,
      $p_{\mathrm{usable}}(\hat f) \ge p^\ast$. Ours estimates both from a
      point prior on utterance length and in-pipeline timings.
    \end{itemize}
  }
\end{frame}

\begin{frame}{Residency alone taxes the recognizer}
  {\centering
  \includegraphics[width=\linewidth,height=0.52\textheight,keepaspectratio]{paper_fig2_occupancy_tax.pdf}\par}
  \small
  \begin{itemize}
  \item A process the size of the language model that only holds pages slows
    the final decode by \TaxBallastA{} and \TaxBallastB{} (two runs, paired).
  \item Mechanism: transparent-huge-page fallback in the decoder's own
    allocations: \AloneFallback{} $\rightarrow$ \BallastFallback{} fallbacks per
    decode.
  \end{itemize}
  \note{
    \begin{itemize}
    \item Recognizer alone: final decode \AloneSTT{}, \AloneFallback{}
      fallbacks per decode, \AloneHuge\,MB of huge pages kept. Inert ballast
      co-resident: \BallastFallback{} fallbacks per decode, \BallastHuge\,MB
      kept.
    \item Paired tax, inert ballast: \TaxBallastA{} and \TaxBallastB{}. Full
      pipeline co-resident: \TaxFullA{} and \TaxFullB{}. 32 turns per
      condition (the 16 dev files, each played twice); the CI resamples the
      files.
    \item Caveats that travel: one run per condition, each made after its
      baseline, so time order is confounded with condition. The two runs
      disagree on the size and on the order of conditions, and only the
      second was instrumented for huge pages. Every interval excludes zero.
    \item Not claimed: that an inert ballast costs as much as a live
      inference server. It does in one run, not in the other.
    \item The figure is the instrumented session: one run per condition.
    \end{itemize}

\begin{frame}{Is a draft usable? The prefix probe}
  \begin{itemize}
  \item Offline, the language model sees the first fraction $f$ of each
    multi-step problem. Its draft is \emph{usable} if its first spoken chunk
    is a word prefix of the full-transcript reply's.
  \item Break-even, from the measured costs: $p^\ast = \BreakEven$.
  \item Greedy usability: \GreedyFifty{} at $f = 0.5$; \GreedySeventyFive{}
    at $f = 0.75$.
  \item The registered test at $f = 0.75$ fires: the value side is closed on
    this corpus. The problems ask their question last.
  \end{itemize}
  \note{
    \begin{itemize}
    \item The 80 seeded multi-step items, run twice: sampling at
      $T = 0.5$, and greedy.
    \item The probe's gate: from the full transcript, greedy answers
      correctly on \GreedyGate{} of the items, passing the registered 30\%
      gate; sampling gives \SampledGate{} and fails it. The curve is the
      greedy one; the live pipeline replies at $T = 0.5$.
    \item At $f = 0.75$: greedy \GreedySeventyFive{}
      (\GreedySeventyFiveK{} items); sampled \SampledSeventyFive.
    \item At $f = 0.9$, exploratory and not the registered test: greedy
      \GreedyNinety{}. The point estimate clears $p^\ast$; the interval
      reaches below it.
    \item $p^\ast$ weighs the overlap cost of a draft still running at the
      endpoint against the time a usable draft saves.
    \end{itemize}
  }
\end{frame}

\begin{frame}{Could a trigger tell?}
  \begin{itemize}
  \item Two triggers for ``more than 900\,ms of speech remain'': semantic,
    on the partial transcript, and acoustic endpoint anticipation.
  \item AUC \TsemAUC{} (semantic) and \EpaAUC{} (acoustic), over
    \TriggerPoints{} decision points from \TriggerUtts{} dev utterances.
  \item Neither is distinguishable from chance, and the intervals are too
    wide to call either useless: \alert{not detectable}, and open.
  \item The acoustic model also runs slower than real time here:
    \EpaRtf$\times$ its audio.
  \end{itemize}
  \note{
    \begin{itemize}
    \item Plus \TriggerUnindexed{} points with no utterance index. The
      registered bootstrap resampled them as one cluster; that is recorded,

    \item ``Not detectable'' is not ``no effect''.
    \item Acoustic model's wall clock: a logged mean of \EpaWall\,s per

      segments.
    \item Reading the triggers on the multi-step set was registered not to
      happen once the probe closed the value side, and it was not done.
    \end{itemize}

\begin{frame}{The allocator never spent the window on a draft}
  Admit a draft of budget $B$ only if $p_{\mathrm{usable}}(\hat f) \ge
  p^\ast$ and $B$ tokens fit in $w(\hat f)$ at the measured decode rate.
  \bigskip

  {\centering\small
  \begin{tabular}{lrl}
    \toprule
    reason & decisions & why no draft \\
    \midrule
    below break-even & \AllocBelow & a draft would fit; usability below $p^\ast$ \\
    infeasible & \AllocInfeasible & usability past $p^\ast$; no room left \\
    \midrule
    all decisions & \AllocDecisions & drafts issued: \AllocSpends \\
    \bottomrule
  \end{tabular}\par}
  \bigskip
  {\small One logged multi-step run (pass 6). Every record carries the inputs
  its reason rests on.}
  \note{
    \begin{itemize}
    \item \AllocDecisions{} decisions in one logged multi-step run:
      \AllocBelow{} below break-even, \AllocInfeasible{} infeasible. It
      spent the window on the drafter \AllocSpends{} of \AllocDecisions{}
      times. $p^\ast = \BreakEven$.
    \item Below break-even: the draft would have fit, but its usability at
      the estimated fraction was below $p^\ast$. Infeasible: usability had
      passed $p^\ast$, and the registered window model left no room.
    \item The full generated Table 2 (median and range of $\hat f$,
      $\hat p_{\mathrm{usable}}$, feasible budget and remaining time, per
      reason) is in the backup slides.
    \item The listener's gate runs independently of the allocator. On a
      task whose questions come early, the same rule would admit drafts
      wherever the measured curve clears break-even within the window.
    \end{itemize}
  }
\end{frame}

\begin{frame}{The listener: commit what agrees, issue what can finish}
  \begin{itemize}
  \item A hypothesis worker decodes only the audio after the committed
    point; LocalAgreement-2 commits the agreed prefix, never a word in the
    last 0.3\,s of the buffer.
  \item At the endpoint the final decodes only the uncommitted tail.
  \item \textbf{Feasibility gate.} Issue a hypothesis only if the decodes
    still needed to commit its words fit in the expected remaining speech.
  \item \textbf{The orphan.} A hypothesis still decoding at the endpoint
    competes with the final for the same cores.
  \end{itemize}
  \note{
    \begin{itemize}
    \item The worker is a separate process running \texttt{tiny}.
      Hypotheses are self-paced at duty $\delta = 0.6$: after a decode of
      measured length $d$, the worker rests $(1/\delta - 1)\,d$. A duty
      near 1 split no more turns; the bound gives the same outcome with
      fewer decodes.
    \item The gate's prior is a point value, the median duration of the
      set's files, derived at run start. On short utterances the gate
      abstains outright.
    \item The first live test (pass 2) ran the listener on every turn, with
      no gate and no freeze: slower than the baseline, with a CI that
      includes zero (Fig.~5).
    \item Two mechanisms were proposed for that failure: the orphan at the
      endpoint, and speculation on utterances too short to pay. The freeze
      and the gate answer them; only the first was tested directly.
    \end{itemize}
  }
\end{frame}

\begin{frame}{Freeze the orphan}
  \begin{itemize}
  \item At the endpoint the orphan is frozen (\texttt{SIGSTOP}). It resumes
    once the recognizer is idle after the reply; its stale result is
    discarded by sequence number.
  \item Against racing it, freezing saves \PnineTTFA{} of paired TTFA
    ($n=\PnineN$ items). The final runs at \PnineRatio{} of the solo model
    of its tail.
  \end{itemize}
  \begin{alertblock}{It holds, with three caveats}
    The CI's lower end lies below the registered 150\,ms bar.
    It holds only under an amendment registered before the run.
    It needs the 3\,s quiet period after each reply.
  \end{alertblock}
  \note{
    \begin{itemize}
    \item P9c, on Spoken-MQA's single-step split: freezing against racing,
      paired TTFA \PnineTTFA{}, $n=\PnineN$ items. Final over the solo model
      of its tail \PnineRatio{}, $n=\PnineRatioN$ items.
    \item The three caveats go with this number every time: (1) the CI's
      lower end is below the registered 150\,ms bar; (2) under the original
      check 2 it would be NOT TESTABLE, and it holds under the amendment
      made before the run; (3) it depends on the 3\,s quiet period after
      each reply.
    \item Costs of the freeze: the resumed decodes still spend energy (two
      slides on); a turn that opens while the worker is frozen issues no
      hypotheses.
    \end{itemize}
  }
\end{frame}

    \item Stale decodes: \StaleN{} discarded, mean \StaleMean\,J, total
      \StaleTotal\,J net; the per-decode median understates the cost. Some
      drew far more power than their length explains, for reasons not
      found.
    \item Worker: PSS \WorkerPSS\,MB at spawn, before any decode
      ($n=\WorkerN$ spawns); the per-decode working set is not logged.
    \end{itemize}
  }
\end{frame}

\begin{frame}{Is the gate enough? A simulated planner}
  \begin{itemize}
  \item A finite-horizon dynamic program over elapsed time, calibrated from
    the logs: decode times, commit boundaries, the final's cost, the
    endpoint hazard.
  \item At the gate's duty bound it beats the gate by a median paired
    \PlannerDP: at the median, the gate is within that of the optimum.
  \item Without the bound: \PlannerNoDuty{}, a gain from decoding back to
    back, not from planning.
  \item Simulated only; no live pass. The remaining gain sits in items
    longer than the gate's prior.
  \end{itemize}
  \note{
    \begin{itemize}
    \item Per-item TTFA reduction of the planner over the gate, multi-step,
      simulated at the calibrated fill ($n=\PlannerN$ items).
    \item The validation is weak. The simulated gate's saving over
      REACTIVE-NOPARTIAL is \PlannerVal{}; the value measured on the same
      items lies just outside that interval. The final's slope was fitted
      largely from the same contrast; the committed fraction is the real
      check.
    \item Commit boundaries no run reached are invisible to the simulator.
      They are filled synthetically, at the one rate that matches the
      measured committed fractions with and without the gate. Richer fills
      and a steeper final-decode slope raise the planner's median gain.
    \item A gate whose prior adapts to elapsed speech is a hypothesis, not
      simulated.
    \item Decision: on the registered statistic, the median paired
      reduction, no live pass. The planner is the formalisation.
    \end{itemize}
  }
\end{frame}

\begin{frame}{Limitations}
  \begin{itemize}
  \item One device class with CPU-bound recognition (a GPU recognizer would
    move the shares); one small 4-bit language model; one synthesizer voice.
  \item Benchmark audio is synthesized speech played in at real time; live
    speech is pending.
  \item The gate's prior is the set's own median duration; a deployment
    would have to learn it.
  \item The tax rests on two runs, one per condition; the thinker's live
    comparison is descriptive; the planner is simulated.
  \end{itemize}
  \note{
    \begin{itemize}
    \item The headline's interval: P3's lower end lies below the 300\,ms
      bar, and the ungated test failed.
    \item The listener's overlap cost, \ListenerC\,ms/s \ListenerCCI, lies
      below the registered band; its scorer was written after the data.
    \item Draft usability comes from an offline probe of the 80 seeded
      items, with no interval on the curve.
    \item The thinker's live comparison (pass 7): its interleaved design
      broke at the first VAD split, and its scorer was written after the
      run.
    \item Drift across dates: part of a cross-date difference in baseline
      TTFA is unattributed. Every claim-bearing comparison has a same-day baseline except
      pass 2, which does
      not.
    \item The freeze: some stale decodes drew unexplained power; a turn that
      opens while the worker is frozen gets no hypotheses.
    \end{itemize}
  }
\end{frame}
